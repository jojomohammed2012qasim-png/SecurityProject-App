## 🛡️ Executive Overview
**Black King** is a high-performance security system engineered in Rust for 64-bit Windows architectures (Windows 7 64-bit through Windows 12). Designed with microsecond response times, it delivers **zero system overhead (0.00% RAM / CPU footprint)** while isolating high-risk threats from the host operating system core.

---

## ⚡ Key Architectural Features

### 🔒 1. Station 1: Sandboxing & Deception Layer
- Traps untrusted executables in an isolated memory space.
- Injects fake system registries and decoy files to force malware into revealing its malicious behavior early.

### 🛑 2. Station 2: Air-Gapped Dark Zone Isolation
- Instantly severs all network interfaces to block command-and-control (C2) communication.
- Implements a **Buffer Wall Protection**, ensuring absolute separation between isolated stations and system files.

### 🧹 3. Station 3: Source Tracking & Secure Purge
- Traces threat origins (e.g., Removable USB devices).
- Encrypts host memory blocks using AES-256-GCM during cleanup.
- Wipes isolated sandbox memory clean in microseconds with zero system traces left behind.
